# 收藏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 各端与 MCP 可新增、查找和使用长期收藏；收藏不进入待办或完成清理。
**Architecture:** 在现有 messages 中添加 collected_at。复用分类、附件和搜索，不复制记录。新客户端显式协商 collections 能力，旧客户端收到收藏记录的删除投影以移除缓存；写入同时校验能力，防止旧版误改收藏。清理与收藏转换需有明确串行顺序。
**Tech Stack:** TypeScript/Kysely/SQLite、React、SwiftUI。
**Spec:** `docs/1.2.1-requirements-2026-11-26.md`

## Global Constraints
- 免费与 Pro 开放收藏；沿用容量、每日新增额度、文件和 MCP 权限。
- 收藏不可转回待办。删除独立；全局分类不引入范围或显示开关。
- 主目录 dev 内执行；每个完整需求本地提交，不推送。

## Review Focus
- 旧客户端缓存、批量完成和删除不能破坏收藏。
- 同时收藏和附件清理不能造成标记永久但文件已丢失。
- 过期或已回收附件不得被收藏复活。
- 用户隔离、并发版本冲突、重试幂等。
- 全局搜索定位、普通列表计数、分类切换和直接新增归属。
