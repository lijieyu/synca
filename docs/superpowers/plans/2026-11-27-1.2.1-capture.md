# 桌面截图 Implementation Plan
Spec: docs/1.2.1-requirements-2026-11-26.md
Goal: Mac/Windows 全局快捷键截图，悬停选窗、拖框、调整选区、矩形标注、撤销、复制/保存/取消。
Architecture: Electron desktopCapturer 取得每屏冻结图；透明无边框的独立沙盒窗口显示同一套本地 Canvas UI。Mac CoreGraphics 小型继承沙盒 helper 只返回窗口边界；Windows PowerShell 内置 .NET 调 Win32 EnumWindows/DWM 返回边界（无第三方安装、无执行策略改写）。主进程将 Windows 物理坐标转换为 DIP。渲染器不访问网络，只有受限 session IPC，取消不改剪贴板。
## Global Constraints
- 免费、不自动上传。快捷键默认 CommandOrControl+Shift+A，可更改；注册冲突显示错误并保留旧快捷键。
- 多显示器各自选区，支持负坐标/Retina/缩放；每次截图只确认一屏区域。
- 权限拒绝明确引导系统设置，绝不请求与截图无关的辅助功能权限。
- 剪贴板只在确认后写入。保存使用系统对话框，取消保存回到编辑；PNG 写入成功才结束。
- 原生包装必须包含窗口边界 helper 并纳入现有签名流程。
## Tasks
1. 选区/坐标/标注边界测试，窗口边界平台桥接与构建。
2. 全局快捷键/菜单入口、冻结图、每屏遮罩与主进程图像输出。
3. 共用工具栏、拖拽/缩放/矩形标注/颜色/线宽/撤销/键盘及三语。
4. 配置入口、错误恢复、测试/构建与本地提交。
## 验收
窗口悬停、点选、拖选、反向拖动、选区调整、矩形撤销、确认复制、保存取消、Esc保留旧剪贴板、DPI/负坐标、快捷键占用、权限拒绝。Windows 运行验收需实际 Windows 环境。
