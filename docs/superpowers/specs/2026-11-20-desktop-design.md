# Synca 桌面改版与交互保全

用户 2026-11-20 授权从确认的 Demo 开始桌面产品实现。Web 和 Electron 共用实现，移动布局后续单独处理，不编译 Windows。不复制 Demo 的简化业务逻辑。

## 目的与取舍
正文优先；分类时间在记录底部、操作在右下。桌面设置为固定尺寸且随窗口收缩的弹窗，账号第一项，外部账号留左下，独立设置按钮替代单薄菜单。分类选中使用自身颜色的低强度底色；未选中以色点识别；全部入口用中性色。桌面搜索固定尺寸，移除分类选择且始终全局搜索；窄屏保留既有范围交互，后续移动改版再处理。同步按钮、Cmd/Ctrl+R、Electron 菜单均走同步，不重载页面。清理扫帚图标保留原样。

实现选择：保留 React 组件、请求及状态管理，只调整呈现和明确授权的入口。拒绝把静态 Demo 重写成新业务层，避免丢掉已打磨的交互。桌面样式限定 >=640px；窄屏主交互和 iOS 不在本轮重构。

## 本轮呈现与验收
- 默认侧栏宽度及限制一字不改；管理按钮与数字列共享对齐轴，添加按钮仍同宽。
- 记录底部为正常文档流，操作显隐不改变高度；悬停、键盘聚焦均可用，触屏不隐藏。
- 桌面账号/设置直接入口；设置内保留账号在上、菜单项显示套餐；一级栏目切换，嵌套页面提供明确返回与关闭。
- 反馈保留提交表单，并提供小红书图标和文字链接；不自动提交反馈。
- 1280×800、640×500、侧栏200/236/360、深浅色、中英文长文案；320/390移动不回归。
- 浏览器 fixture 行为回归不触碰真实数据；Electron临时配置/本地服务验证后才替换Mini安装；Web仅preview，不发布正式服务。
- 现状基线快照独立于本轮改动。原仓库的iOS、后端及未提交修改保留不动。
