## 运行问题与修复

- Windows 临时目录文件 URL 的 `~` / `%7E` 等价编码导致自身 IPC 被拒绝：按本地文件路径比较，同时保留主框架、来源和无查询参数限制。
- PowerShell 动态编译枚举窗口启动过慢：替换为随包提供的 x64 / ARM64 原生小程序，运行时不启动 PowerShell。
- 无边框、禁止缩放组合阻止 Windows 全屏尺寸正确生效：截图覆盖层使用可缩放的全屏窗口，保留无窗口控件的交互。
- 当前 Electron 图片剪贴板已改为异步 `ClipboardItem`，截图模块旧 `writeImage` 调用失败：复用项目已有异步接口，成功才关闭、失败保持编辑。同步修正掩盖错误的测试模拟。
- 更新验收程序曾把异步轮询误当完成：改为在测试主进程等待真实 ready 状态，并分离调试器退出与新进程启动证据。
