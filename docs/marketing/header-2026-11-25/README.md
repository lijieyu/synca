# Product-page header draft

Scope: the App Store product-page header (ASC “标题和搜索结果 → 标题”), not the first screenshot. The current slot was inspected in ASC on 2026-11-25: its logo/slogan repeats the product identity shown immediately below it.

The new language-neutral draft removes logo, slogan and device screenshot repetition. Sparse paper/image/record shapes and a restrained lavender line imply capturing and passing content; these are editorial illustrations, not a fabricated product UI. The EverBond reference is its accepted whitespace principle, not its sky/skin imagery.

Apple's current dedicated header specification is 3840×1646 PNG without alpha. Essential artwork is within x1097/y493, width1646/height661. Source and geometry are recorded in manifest.json. The full-resolution opaque export and a safe-area review preview are retained at the manifest's export directory. User acceptance, ASC upload and actual device-slot preview are pending; no live creative asset was removed or replaced.

The SVG is editable and contains no localized text. The same graphic can be used for Simplified Chinese, Traditional Chinese and English, subject to actual ASC preview. Do not reuse this crop for search-result artwork without composing to that separate slot's specification.
