## 发布条件与文案边界

- 当前 ASC 正式 iOS/macOS 均为 1.1.0；Mac 1.2.0 处于 TestFlight 阶段，iOS 邮箱登录已进入下一包代码。不能把以下文案当作当前正式版功能公告。

- 免费版支持文字、图片、分类及搜索；普通文件传输、外部 AI 连接为 Synca Pro。附件有期限，终身购买不是永久附件存储。当前源码额度为：免费每日 20 条、100 MB、3 天；Pro 新增记录不限量、1 GB、30 天。须与发布时正式服务回读核对后使用。
- AI 是经用户授权后由兼容 MCP 的外部客户端访问 Synca；不提供内置模型或聊天服务，不承诺外部服务免费。
- 本次计划同步发布正式 Web 邮箱登录。公开文案自然描述 Apple/邮箱登录和双向绑定，不加入构建版本或开关等实施细节；实际公开状态由最终发布回读确认。

```text
灵感记录，即刻同步。

Synca 帮你快速记下想法、收集待办、传送图片和文件。在手机上先记下来，再到电脑上接着处理，让工作笔记和日常灵感随时在手边。

随手记录
• 保存文字与图片，支持基本 Markdown 显示。
• 编辑文字，按分类整理记录，完成一项就标记处理。

• 在 iPhone、iPad、Mac 与网页版之间继续使用同一账号的记录。

• Synca Pro 支持普通文件传输，把需要的附件带到另一台设备。

让 AI 用上你的记录
Synca Pro 可连接支持 MCP 的外部 AI 应用。经你授权后，AI 可以查找、整理记录，并把讨论结果保存回 Synca。需要自行使用兼容的 AI 客户端；Synca 不内置 AI 模型或聊天服务，外部服务的要求及费用由其提供方决定。

选择适合你的登录方式
使用 Apple 或邮箱验证码登录，无需为邮箱登录设置密码。可在账号设置中绑定另一种登录方式：Apple 账号添加邮箱，邮箱账号绑定 Apple，继续使用同一账号的记录。不同账号不会自动合并。

Synca Pro 不限新增记录数量，支持普通文件传输与 AI 连接，提供 1 GB 附件空间，附件保留 30 天，通过 App 内购买解锁。
附件到期后自动删除，重要图片和文件请提前另存。文字记录不随附件到期删除。终身购买解锁功能，不代表永久保存附件。

官网与下载：https://synca.haerth.cn/home/
网页版：https://synca.haerth.cn/
```

```text
Synca is a personal capture and cross-device sync app for text, images, and files. It uses the user's Synca account to synchronize records; it is not a messaging service between different users.

Version 1.2.0 adds email verification-code sign-in alongside Sign in with Apple. To use email sign-in, choose the email option on the login screen, enter an email address, request a code, and enter the six-digit code delivered to that inbox. No password is used for this flow. If a message is not visible in the inbox, check the junk folder. A new email creates an account after verification. Account settings supports linking in both directions: an Apple-linked account can add a login email, and an email account can link Sign in with Apple. Both methods then access the same Synca account and records. Separate existing accounts are not automatically merged.

Basic review flow:
1. Sign in, create a text record, and send an image.
2. Create or select a category, edit the text, and mark the record as handled.
3. Search for the text or attachment filename and open the result.
4. Sign in to another supported client with the same account to verify sync.

Ordinary file uploads and external AI connections require Synca Pro, available through In-App Purchase. The free plan supports text and images. Attachments are temporary: the current free plan retains them for 3 days and Pro for 30 days. Text records do not expire with attachments. Lifetime purchase unlocks features and does not provide permanent attachment storage.

The Connect AI entry opens Synca's connection guide. AI functionality is provided by a separate compatible MCP client, after explicit OAuth authorization from the user. Synca does not embed an AI model, provide an AI chat service, or require an external AI client for ordinary recording and sync. The guide and connection entry are not evidence of a completed connection; review of AI operations requires an authorized compatible client.

The Windows download is a separate companion client distributed from our website; it is not an iOS or Mac App Store in-app download. This release also enables email sign-in on the public web client. Account settings supports the same Apple/email linking model.
```
