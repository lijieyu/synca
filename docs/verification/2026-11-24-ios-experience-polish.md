# iOS 手机侧栏、设置与同步修正

## 范围

基线 `9a8a2d5`。仅原生客户端及测试文档；未修改或部署正式 Web、后端。原始工作区里的未提交草稿保持原样，选择性恢复已批准的手机界面，保留当前通知同步与搜索实现。

- iPhone：左侧分类抽屉；左上当前分类与数量；右上保留搜索、同步、原扫帚。抽屉保留分类颜色、计数、宽加号、管理与底部账号入口。
- 原生设置：账号优先，不在设置入口显示套餐；显示偏好、分类、连接 AI、反馈、关于；原生返回与完成。账号页展示当前套餐，购买权益保持原流程，退出和删除分开。
- 分类管理：常显编辑、删除与系统拖动手柄；默认分类名称只读，编辑标题正确；重排复用现有保存/失败回滚。
- 反馈：固定大尺寸表单、去冗余图片文案、小红书真实图标。原生关于页去备案号。
- iPad：支持横竖屏/调整窗口，设置为系统 sheet。通知生命周期由 App 汇总所有场景管理；设置遮住主页面不再停流，单个 iPad 窗口退后台不停止另一个活跃窗口的同步。
- 初始加载完成后返回设置/搜索不重复全量加载；不改变拼音搜索和记录呈现/滚动算法。
- APNs：从签名描述文件解析真实环境；旧安装补登记 topic/environment，避免错误环境被旧去重标记锁住；推送同步失败回报 failed，不再额外用旧数量覆盖角标。

4. 消息索引/变更合并：会话隔离、并发修改保护、删除墓碑、重叠时间游标、分类元数据及一万条记录索引通过。拼音/首字母/中英混输/长内容搜索已有本轮通过结果。
5. 连接 AI：真实共享 Web 界面在原生容器加载，使用本地免费/Pro 权益，入口与返回、免费/Pro/深色黑白操作按钮通过；不代表真实 AI OAuth 已重新授权。

6. iPad 横屏：主界面和居中设置完整可见，默认分类只读/正确标题/取消后仍返回分类管理，再返回设置；测试通过。截图使用 XCUIScreen，避免 XCUIApplication 在横屏中错误裁剪。
