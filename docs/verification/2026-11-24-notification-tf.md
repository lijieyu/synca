## 实机验收

1. Mac 登录与 Web 相同账号；Web 新增、编辑、完成和删除一条测试记录，Mac 应自动反映，数字准确。
2. Mac 按 Command-W 关闭窗口但不退出应用；在 Web 改变待办数量，Dock 角标应随之更新；重新打开时保留原草稿和位置。
3. iOS 允许通知，进入后台后从 Web 改动待办，检查角标和回前台同步；静默 APNs 可能受系统调度影响，不能以一次未即时刷新认定数据丢失。
4. SSE 与 APNs 都能触发同步，单看角标无法证明 APNs。APNs 独立验收需同时核对新包 token 登记、服务端投递结果与客户端收到事件；不要把 SSE 的成功当作 APNs 成功。
5. 断网后恢复，或睡眠后唤醒，记录/分类应补齐，草稿与搜索定位应保留。Command-R 仍只同步，不重载页面。
