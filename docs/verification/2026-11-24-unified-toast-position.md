# Web / Electron Toast 定位一致性 — 2026-11-24

问题：同步成功使用主内容顶栏的中心，普通 Toast 却固定在整个窗口的 left:50% / top:64px。保存及错误提示因此偏左、压住分隔线，且不能随侧栏宽度改变。

修复共用 Toast，保留原有成功绿底、错误红底、显示时长及文案：

- 普通提示跟随主内容顶栏水平/垂直居中，排除侧栏宽度。
- 通过 Portal 脱离滚动列表及编辑器的布局影响，随窗口、侧栏和活动弹窗变化重新定位。
- 长错误会换行；当小窗口顶栏不能容纳时，置于顶栏下 12px，避免压线或遮住操作按钮。
- 设置或模态窗口打开时相对当前内容标题区域定位。表单就地错误保持原位。
- 多条瞬时提示只显示最后一条，普通 Toast 显示期间不与同步成功提示重叠。
- 保留 status / alert 语义，支持减少动态效果及高对比度；不抢键盘焦点或拦截鼠标。

## 验证

先运行位置测试，Web 与 Mac 布局的 1280/640px 均因横向位置不同失败。修复后 9 项浏览器检查通过：四种桌面几何布局、两种实际保存/复制失败/发送失败路径、手机长提示、同步草稿保持、既有同步提示布局。额外回读 Mac 布局两种尺寸的深色截图。

覆盖侧栏拖宽、640×500 最小窗口、390×844 手机、设置窗口、长英文错误、颜色和可访问角色、提示重叠、失败保留草稿。Web 生产构建与 Electron 共用前端构建通过。Mac 布局验证为浏览器中的桌面桥接模拟，不是新的 TF 包；本次不触发客户端打包。
