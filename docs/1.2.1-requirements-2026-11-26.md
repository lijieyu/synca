# Synca 1.2.1 需求讨论记录

更新日期：2026-11-26。以下为用户确认的产品方向，不代表代码已实现或发布；具体工程方案及验收待补齐。

## 已确认方向

- 草稿本：每账号一页，全端自动保存和同步，随时续写；支持 Markdown 和图片，侧栏独立入口。离线保存、冲突保留、图片长期保存需要设计。
- 升级：Windows 本次支持下载后重启自动更新，包含现有便携包迁移评估；iOS 和 Mac 商店版检查后跳转商店更新。
- 桌面账号菜单：删除菜单顶部重复头像，保留账号信息；底部账号入口不在本次删除范围。
- 截图：Mac、Windows 一致体验；全局快捷键、鼠标悬停拾取窗口、点击锁定或拖框选区、矩形标注、确认复制到剪贴板、保存、取消。快捷键及工具栏细节待设计。

## 收藏：最终取舍

- 收藏为长期资料区域，不是待办。支持普通文字、账号资料、图片和文件，不做专门的密码管理。
- 待办进入收藏是快捷路径：从普通待办列表移出，不计入待办数字，不显示完成按钮，不因原完成状态变灰。
- 不提供移回待办/取消收藏的往返操作；删除是独立操作。也可在收藏中直接新增。
- 侧栏提供收藏入口；进入后侧栏选中收藏，点击外侧分类返回普通待办视图。
- 分类全局一套，只有一个管理入口；不建立收藏专用分类管理，不增加“在待办侧栏显示”开关，不建立分类适用范围。
- 接受收藏使用的分类也出现在全局侧栏，不通过数量自动隐藏。
- 收藏页提供分类筛选，当前讨论采用下拉；默认可查看全部。新建默认采用当前筛选分类，全部视图下采用系统默认分类；新增时显示实际归属。
- 全局搜索同时检索待办与收藏，结果明确标记收藏；收藏页不另做搜索。附件正文/OCR 不在当前承诺范围。
- 收藏不插入普通待办排序，不置顶、不设普通列表内收藏折叠区。
- 附件长期保留、不按普通待办附件期限清理，仍受容量限制；已过期附件不能凭收藏恢复。具体配额和套餐规则待定。
- 多端及 MCP 均需支持收藏及分类、搜索语义。

## 免费 / Pro 边界（已确认）

- 截图与升级提醒免费。
- 草稿本、收藏向免费用户开放。
- 图片和文件统一计入现有账号容量：免费 100 MB，Pro 1 GB；不为草稿、收藏各赠送一份容量。
- 普通文件上传和 MCP 继续沿用当前 Pro 权限。
- 长期保存不等于无限容量；既有附件转换到收藏不可重复计费。

## OSS 暂缓（已确认）

继续使用现有服务器云盘，不开通 OSS，不迁移久念媒体。原因是磁盘有余量，当前阶段新增费用与迁移复杂度超过即时收益。开发收藏与草稿时落实附件引用、权限、容量与清理保护；生产备份现状需独立核查，未声称已验证。

## 开发顺序和执行边界

1. 菜单精简与版本基线核查。
2. 收藏：服务端迁移、权限、配额、旧客户端兼容、清理保护，再接 Web/Electron、iOS 和 MCP。
3. 草稿本：本地恢复、同步版本冲突、Markdown 和图片，再接各端入口。
4. 升级：版本清单与商店跳转；Windows 安装与更新链路、旧便携版迁移。
5. 截图：先验证双平台窗口拾取与权限，再实现共同的选区、标注及剪贴板交互。

## 实现默认值（工程建议，不冒充新增用户要求）

- 草稿首版沿用 Markdown 文本编辑及预览方向，不默认引入完整富文本文档系统；图片必须使用持久附件标识，不写入会过期的签名链接。
- 自动保存先持久化本机，再同步服务端；并发冲突保留双方副本，不静默用后写覆盖。
- 容量不足阻止新增附件，不影响已有资料读取、文本编辑、删除和释放容量。
- 截图仅在用户调用时获取屏幕，默认复制结果，不自动上传或保存到收藏。
- Windows 先验证安装包及签名条件，不自动购买签名证书或声称未签名包没有系统提示；重启更新前保存本地草稿。
