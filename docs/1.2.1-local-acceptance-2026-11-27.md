## 独立评审后的修复

- 草稿每个 Web 编辑实例保存独立未同步副本，另一个标签页的云端轮询不会覆盖它；恢复副本可显式删除。
- “使用云端”通过专用事务接口保存本地副本并读取当前云稿，不再用伪造版本号触发冲突。第三台设备同时保存不会被该操作覆盖。
- 草稿操作绑定原账号和会话；服务端验证 `X-Synca-Account`，图片上传也受保护。补齐跨域允许头。
- 后台角标排除收藏及草稿图片；图片删除失败保留可重试的清理时间。
- 补齐部署代理、桌面本地代理及能力头；本地附件地址映射保留同源鉴权，不改写用户文本；可变 Windows `RELEASES` 清单必须重新验证缓存。
- Windows 构建改用 junction 和 Node CLI，补安装器 description。仍需 Windows 实机打包、安装与升级验收。
- 截图输出校验 PNG 签名、尺寸和像素上限；保存对话框返回后重新检查会话，取消不会误写或关闭新会话。
- 草稿／收藏页面禁用菜单和快捷键清理待办；iOS 收藏显示新增实际归属。
- 视觉验收发现的原生**草稿本预览** Markdown 标题问题已修复，增加标题、代码块、引用的呈现；标题具备可访问性标记。此处不代表待办／收藏记录的 Markdown 渲染能力已全面对齐，记录列表的后续差异见 [11 月 28 日核查](markdown-native-parity-2026-11-28.md)。

## 复现入口

在 `backend` 执行 `./node_modules/.bin/tsx tests/acceptance-server.ts` 启动仅回环的临时测试服务（Ctrl-C 清理数据库和媒体）。在 `desktop` 执行 `npm run build:ui`，再以 `SYNCA_CAPTURE_DIR` 指向截图目录运行 `node acceptance.smoke.mjs`。该脚本只连接本地 fixture；退出后关闭 Electron 并删除临时配置。

原生先运行 `ios/Tests/ExperienceRegression/make-fixture.py` 生成新的临时副本，再将 `Release121Tests.swift` 放入其 UITests，使用本地 fixture 的示例分类／消息代替初始 seed；XcodeGen 生成后只运行 `PolishUITests/Release121Tests`。遵守现有模拟器复用约定，不创建新设备。
