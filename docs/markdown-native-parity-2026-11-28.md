## 根因与范围

待办／收藏的 iOS 和原生 macOS 使用同一个 `MessageMarkdownRenderer`，只对列表、引用及行内格式做了处理。Web／Windows 使用已扩展的 `react-markdown`，支持块级标题。原生草稿本预览另有分块逻辑，之前的草稿本标题修复未覆盖记录列表。

本次修复记录中的独立 ATX 标题（`#` 到 `######`），保留原生 TextKit 渲染、选择、链接与折叠。标题字号按 Web 的 1.55 / 1.4 / 1.25 / 1.15 / 1.075 / 1 倍正文缩放，使用系统字体与语义颜色；正文基准随 Dynamic Type 更新。iOS 添加标题级别属性，macOS 添加段落标题级别。没有改写存储、编辑或复制的原文。

## 当前差异（源码核查，不代表线上版本已更新）

| 记录格式 | Web／Windows | 原生 iOS／Mac |
| --- | --- | --- |
| 粗体、斜体、行内代码、链接 | 支持 | 支持 |
| 基础列表、引用 | 支持 | 支持；复杂嵌套解析并非同一实现 |
| 独立 `#` 至 `######` 标题 | 支持 | 本次补齐 |
| Setext 标题、列表或引用内部标题 | 支持 | 本次未补齐 |
| 表格、围栏代码块、分隔线、删除线、下划线 | 支持 | 未对齐 |
| Markdown 任务复选框 | 支持，部分场景可操作 | 未对齐 |
| 远程 Markdown 图片 | 保留源文本，不自动加载 | 保留源文本，不自动加载 |

这是对已有体验缺陷的修复，不扩展为完整富文本编辑器。本次不修改 Web／Windows 产品代码，不触发发布。
