## 应用介绍
Synca 帮你把临时想法、待办事项和常用资料留在一个随时能找回的地方。

快速记录文字和图片，用分类整理日常信息。需要长期保留的内容可以放入收藏；打开草稿本，就能接着写同一页 Markdown 草稿，也可以插入图片。登录同一 Synca 账户后，在 Windows、Mac、iPhone、iPad 和 Web 之间同步内容。

Windows 版提供桌面快捷键截图：选择窗口或拖动框选区域，添加矩形标注，然后复制到剪切板或保存为 PNG。截图不会自动上传。

免费账户可使用文字与图片记录、草稿本、收藏和截图，图片与文件共用账户现有容量。普通文件上传和 MCP 等 Pro 能力需要对应权益；应用会显示当前可用额度。现有订阅和权益跟随 Synca 账户，不需要为了更换设备重复购买。需要网络和 Synca 账户才能使用跨设备同步。

微软商店版本通过 Microsoft Store 获取更新。

## 功能条目
- 文字和图片快速记录，复用分类整理信息。
- 收藏长期保留资料，不计入待办数量。
- 一页持续续写的 Markdown 草稿本，自动保存与同步。
- 全局搜索同时找回待办和收藏。
- 快捷键截图、窗口选择、区域框选与矩形标注。
- 浅色和深色外观，跨设备使用同一个账户。
