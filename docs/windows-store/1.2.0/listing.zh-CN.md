## 介绍
Synca 帮你快速留下想法、待办和日常信息，并在自己的设备之间同步。

记录文字和图片，用分类整理信息；使用 Markdown 表达重点，把待办标记完成，再通过搜索找回需要的内容。登录同一 Synca 账户后，可以在 Windows、Mac、iPhone、iPad 和 Web 之间继续使用。

免费账户可使用文字与图片记录，内容受账户容量限制。普通文件上传、MCP 等能力需要相应 Pro 权益；权益跟随 Synca 账户。跨设备同步需要登录和网络连接。

微软商店版本由 Microsoft Store 管理安装和更新。首次使用商店版需登录 Synca 账户，云端内容会按原有同步功能读取；官网版的本地资料不会被删除。
