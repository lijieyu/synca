# Synca 1.2.0 (89) — Microsoft Store 繁體中文資料

產品名稱：Synca · 筆記與檔案傳輸

狀態：已儲存至提交草稿，尚未送交認證。

簡短描述：隨手記錄靈感、待辦與資料，在自己的裝置間接著使用。

Synca 幫你快速留下想法、待辦事項與日常資訊，並在自己的裝置之間同步。

記錄文字與圖片，用分類整理資訊；使用 Markdown 表達重點，將待辦事項標示完成，再透過搜尋找回需要的內容。登入同一個 Synca 帳戶後，可以在 Windows、Mac、iPhone、iPad 與 Web 之間接著使用。

免費帳戶可使用文字與圖片記錄，內容受帳戶容量限制。一般檔案上傳、MCP 等功能需要相應的 Pro 權益；權益跟隨 Synca 帳戶。跨裝置同步需要登入與網路連線。

Microsoft Store 版本由商店管理安裝與更新。首次使用商店版時需登入 Synca 帳戶，以原有同步功能讀取雲端內容；官網版的本機資料不會被刪除。
