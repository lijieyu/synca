## Description
Synca keeps quick thoughts, everyday tasks and useful references within reach.

Capture text and images, organize them with categories, and keep lasting information in Collections. The Scratchpad is one continuous Markdown page with image support: open it whenever you want to keep writing. Sign in to the same Synca account to sync across Windows, Mac, iPhone, iPad and the Web.

The Windows app includes keyboard-driven screen capture. Pick a window or drag a region, add rectangle annotations, then copy the result to the clipboard or save a PNG. Captures are not uploaded automatically.

Free accounts can use text and image records, Scratchpad, Collections and screen capture within the account’s storage allowance. General file uploads and MCP access require the corresponding Pro entitlement. Existing account entitlements follow you across devices. An account and an internet connection are required for cross-device sync.

This edition receives updates through Microsoft Store.
